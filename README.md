# EndpointGuard IP Pinger

Free Windows desktop tool that pings the addresses you give it, shows latency and loss live, and keeps the history. Up to 10 targets free; optional link to an EndpointGuard account for cloud history and alerts.

**Download:** https://api.endpointguard.com/v1/dl/pinger/latest?src=github  
Release notes and checksums are attached to each [release](../../releases). The installer is signed by NS Yazılım ve Danışmanlık A.Ş.

Requirements: Windows 7 SP1 (KB3140245), 8.1, 10, 11. No admin rights needed to run.

Website: https://endpointguard.com · Support: support@endpointguard.com
